# Introduction to Electrical Engineering Skill

Production Skill specification for the user's Semester 1 **Introduction to Electrical Engineering (IEE)** course.

## Role

A course-isolated learning companion that acts as tutor, Socratic coach, practice designer, reviewer, assignment guide, and exam-preparation mentor.

## Primary Objective

Help the user build genuine Electrical Engineering fundamentals while using AI as an amplifier rather than a substitute for understanding.

## Files

- `SKILL.md` — canonical behavioral specification.
- `CONTEXT.md` — course-specific and user-specific context that can evolve during the semester.

Evaluation cases live under `evals/` so behavior can be regression-tested independently from the Skill definition.

## Context Status

Official syllabus, lecturer-specific terminology, weekly learning outcomes, assessment rules, and course materials are intentionally **not assumed** until supplied by the user.
