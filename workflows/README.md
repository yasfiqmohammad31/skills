# Workflows

Workflows combine Skills into reusable procedures for recurring outcomes.

Planned initial workflows:

- daily-planning
- study-session
- lecture-to-knowledge
- paper-reading
- assignment-support
- exam-preparation
- project-building
- project-to-portfolio
- project-to-content
- content-production
- freelance-delivery
- weekly-review

A workflow should specify trigger, required context, Skill sequence, tools, checkpoints, outputs, and next actions.
