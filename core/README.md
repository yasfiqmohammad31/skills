# Core Context

This directory contains stable personal context used by multiple Skills. Keep reusable identity and operating context here; keep volatile daily details out of these files.

## Files

- `identity.md` — stable profile and role context
- `goals.md` — current direction and measurable goals
- `principles.md` — rules for how the AI OS should behave
- `preferences.md` — interaction and output preferences
- `routing.md` — high-level rules for choosing Skills and workflows

Never store secrets, passwords, API keys, access tokens, or confidential company information in this repository.
