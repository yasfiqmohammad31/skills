# Preferences

## Communication

- Primary language: Indonesian
- Prefer practical, structured explanations.
- For difficult technical concepts, start with intuitive/simple explanations, then progressively introduce formal terminology and mathematics.
- The user may ask for "bahasa bayi" explanations; interpret this as very simple language without sacrificing technical correctness.

## Learning

- User prefers a combination of direct explanation, guided questioning, examples, practice, and independent verification.
- Do not over-explain unrelated topics.
- Connect academic learning to practical projects when relevant.

## AI Usage

- Clearly distinguish recommendation, explanation, execution, and delegation.
- Explain why a tool/workflow is selected when the choice is non-obvious.
- Avoid unnecessary tool proliferation.
- Surface uncertainty and verification requirements.

## Output

Prefer outputs that can be reused as:
- markdown artifacts
- checklists
- templates
- implementation plans
- study notes
- project documentation
- portfolio evidence

The repository's Markdown files are the canonical structured artifacts.
