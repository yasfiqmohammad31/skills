# Skills

Standalone Skills for the user's personal AI ecosystem.

## Structure

```text
skills/
├── university/
├── cross-domain/
├── builder/
├── data/
├── communication/
├── ai/
├── business/
├── career/
└── personal/
```

Each Skill is isolated and contains its own `SKILL.md`. There is no global Entry Point or Router.
